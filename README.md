## Part A - 1D array of Integers
### Write proram that: 
> * Declares a 1D array of integers. 
> * Traverses the array and displays all elements. 
> * Inserts a new element at a specific position.
> * Deletes an element at a given index.
> * Displays the updated array after each operation.

## Final output scenario:
```
Initial array: [5, 10, 15, 20, 25]

Enter the element to insert: 30  

Enter the position to insert: 5

Array after insertion: [5, 10, 15, 20, 25, 30]

Enter the position to delete: 4

Array after deletion: [5, 10, 15, 20, 30] 
```

## Part B – 2D Array Basics  
### Write a program that: 
> * Declares a **2D array** (e.g., 3×3).
> * Accepts values for the **2D** array from the user.
> * Displays the **2D array** in tabular form.
> * Allows traversal: print each row and column element. 

# Final output scenario: 
```
Input 2D Array (3x3):
o 1 2 3
o 4 5 6
o 7 8 9
Output (Traversal):
o Row 1: 1 2 3 
o Row 2: 4 5 6 
o Row 3: 7 8 9 
```
